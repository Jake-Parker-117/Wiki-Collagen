# Wiki Collagen:

## https://wikicollagen.org/

## Description:
A web-app containing two bioinformatics tools:
- Collagen Detector: instant collagen triple helix domain identification in protein sequences via regex pattern recognition.
- CollagenAI: a fine-tuned ESM-2 protein language model for collagen and CLP classification.
