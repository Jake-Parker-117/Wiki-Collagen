What is Wiki Collagen?

Wiki Collagen is a free and open source webapp containing two Collagen-focused bioinformatics tools: Collagen Detector and CollagenAI.

Collagen Detector methodology, inputs, and outputs:


Collagen Detector uses regular expressions to identify the repeating GXY amino acid patterns within collagen domains and this doesn't take homology or probable helix formation into account. Therefore, short repeating collagen domains interspersed with short interruptons are highlighted as such rather than continual collagen domains. This is not a reflection of the nature of that domain, but rather the seqeunce analysis

Collagen Detector takes .fasta, .fa, .faa, and .txt files.
The minimum length for a collagen domain in triplets (default=10) and the maximum length of a GNG interruption (default=12, ie. G3-12G) can be adjusted by the user.

This tool provides 3 outputs: a flattened fasta .txt file containing the collagenous proteins, an html file with the same protein sequences and highlighted collagen domains and interruptions and a .txt file containing interruption and GXY prevalence statistics.

Colalgen Detector Highlighted output:


Non collagen triple helix regions are not highlighted, collagen domains are highlighted in yellow, GXG interruptions are highlighted in green, GNG interruptions are highlighted in cyan and GGG repeats are coloured red.

Example highlighted sequence: DSRSTEKTTGPTGLKGESGTATSTGTSGPAGLPGYGVKGHQGGGGGG

CollagenAI methodology, inputs, and outputs:


CollagenAI is a fine-tuned ESM-2 650M parameter model with a Collagen-specific classification head designed to produce a predicted classification for Collagen and CLP seqeunces into one of 11 classes.

Collagen Classes: Fibrillar, Network, FACIT, Multiplexin, MACIT, Misc. Collagen
CLP Classes: Transmembrane CLP, C1q-containing CLP, C-type lectin-containing CLP, Ficolins, Misc. CLP
See list below for more details

CollagenAI takes .fasta, .fa, .faa, and .txt files.
The minimum confidence (default=80%) can be adjusted by the user.

This tool outputs a .txt file containing the Headers of each sequence in the input with the predicted class and confidence below.

Privacy Notice and Disclaimers:


Privacy Notice:

User information (eg. email, name, and private information) submitted via the contact form will be deleted within 1 month of submission. No user information is stored and all sequences are deleted after 1 hour. Please contact us if you have any questions.


Disclaimers:

  1. Collagen Detector is not designed to determine if the collagens, collagen-like proteins are helix forming or if they are true collagen domains but rather to recognise the collagen domain GXY pattern in amino acid sequeneces.
  2. Any gap characters (eg. -, * or ~) used to denote unknown amino acids will be removed from the sequences during processing by Collagen Detector.
  3. If FASTA headers and sequences are not separated by a newline character (\n) the Collagen Detector will run on the header aswell as the sequence. It will also provide warnings in the output files for non-separated sequences, but will still provide a correct output.
  4. Unseparated headers or ambiguous characters will be incorporated into the CollagenAI predictions incorrectly. Please remove any ambiguous characters and use standard FASTA formatting
